2. What is Nginx, and what does it do on this server?

A web server that serves your website to visitors. It also functions as a reverse proxy and load balancer, directing traffic to backend servers and improving both site performance and security.

Web serverServes the website to visitors.
Reverse proxyDirects traffic to backend servers.
Load balancerImproves site performance and security.

3. Which commands did I use?

  1. sudo apt update

    Updates the package lists on a Linux system.

  2. sudo apt install nginx

    Installs the Nginx web server on a Linux system.

  3. y

    Accepts the installation prompt.

  4. sudo ufw allow 'Nginx Full'

    Configures the firewall to allow both HTTP and HTTPS traffic, so users can access the website.

  5. sudo reboot

    Restarts the Linux system immediately.

  6. sudo nano /var/www/html/index.html

    Opens the index.html file in the Nano text editor with administrator (root) privileges.
